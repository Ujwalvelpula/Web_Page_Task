# 🎗️ Cancer Awareness & Support Website

A simple, responsive web page created to spread awareness about cancer and provide emotional support through positive messaging.

## 📌 Features

- 🎯 **Landing Section**
  - Clear message promoting cancer awareness and support

- 🖼️ **Banner Section**
  - Clean awareness banner for visual impact

- 💬 **Rotating Quotes Section (Bonus)**
  - Inspirational quotes that change automatically
  - Smooth fade animation
  - Implemented using JavaScript

  - Name, Email, Message fields
  - Frontend-only (no backend required)

- 📱 **Responsive Design**
  - Works well on mobile, tablet, and desktop devices
